# Phase 3: SQL for Data Science — Topic 6: GROUP BY

GROUP BY is used to group rows that have the same value in one or more columns. It is mainly used when you want to perform calculations for each group.

For example:
- Total sales by region
- Average salary by department
- Number of customers by city
- Total orders by product
- Maximum transaction by category

## Basic Syntax

```sql
SELECT column_name, aggregate_function(column_name)
FROM table_name
GROUP BY column_name;
```

Common aggregate functions:
- `COUNT()` → Count rows
- `SUM()` → Calculate total
- `AVG()` → Calculate average
- `MIN()` → Find minimum
- `MAX()` → Find maximum

## Simple Example

Suppose we have:

| department | salary |
|---|---|
| IT | 60000 |
| IT | 80000 |
| HR | 50000 |
| HR | 70000 |
| Finance | 90000 |

Query:

```sql
SELECT department, AVG(salary) AS avg_salary
FROM employees
GROUP BY department;
```

Result:

| department | avg_salary |
|---|---|
| IT | 70000 |
| HR | 60000 |
| Finance | 90000 |

Instead of calculating one overall average, SQL calculates an average for each department.

## GROUP BY with COUNT()

To count employees in each department:

```sql
SELECT department, COUNT(*) AS employee_count
FROM employees
GROUP BY department;
```

Result:

| department | employee_count |
|---|---|
| IT | 2 |
| HR | 2 |
| Finance | 1 |

## GROUP BY with SUM()

Suppose you have sales data:

| region | sales |
|---|---|
| North | 10000 |
| North | 15000 |
| South | 20000 |
| South | 12000 |

Query:

```sql
SELECT region, SUM(sales) AS total_sales
FROM sales
GROUP BY region;
```

Result:

| region | total_sales |
|---|---|
| North | 25000 |
| South | 32000 |

This is extremely common in business analytics.

## GROUP BY with MAX()

Find the highest salary in each department:

```sql
SELECT department, MAX(salary) AS highest_salary
FROM employees
GROUP BY department;
```

## GROUP BY with MIN()

Find the lowest salary in each department:

```sql
SELECT department, MIN(salary) AS lowest_salary
FROM employees
GROUP BY department;
```

## GROUP BY with Multiple Columns

You can group by multiple columns.

```sql
SELECT department, job_title, COUNT(*) AS employee_count
FROM employees
GROUP BY department, job_title;
```

Here SQL creates groups based on department + job_title.

For example:

| department | job_title | employee_count |
|---|---|---|
| IT | Analyst | 5 |
| IT | Developer | 8 |
| HR | Analyst | 3 |
| Finance | Manager | 4 |

## GROUP BY with WHERE

WHERE filters rows before grouping.

```sql
SELECT department, AVG(salary) AS avg_salary
FROM employees
WHERE salary > 50000
GROUP BY department;
```

## GROUP BY with ORDER BY

You can sort grouped results.

For example, find departments with the highest total salary first:

```sql
SELECT department, SUM(salary) AS total_salary
FROM employees
GROUP BY department
ORDER BY total_salary DESC;
```

This is very useful for ranking groups.

## GROUP BY vs DISTINCT

These two can sometimes look similar.

**DISTINCT:**
```sql
SELECT DISTINCT department
FROM employees;
```
Used to find unique departments.

**GROUP BY:**
```sql
SELECT department, COUNT(*)
FROM employees
GROUP BY department;
```
Used when you want to perform calculations for each department.

Simple rule:
- DISTINCT → Give me unique values
- GROUP BY → Give me groups so I can calculate something

## Real-World Data Science Example

Imagine an e-commerce dataset. You want to know the total revenue generated by each product category.

```sql
SELECT category,
       SUM(quantity * price) AS total_revenue
FROM sales
GROUP BY category
ORDER BY total_revenue DESC;
```

This gives you a category-level summary that can be used for:
- Revenue analysis
- Product performance
- Business reporting
- Feature creation
- Exploratory data analysis

## Common Mistake

Consider:

```sql
SELECT department, employee_name, AVG(salary)
FROM employees
GROUP BY department;
```

This can cause an error in many SQL databases because `employee_name` is neither:
- included in GROUP BY, nor
- used inside an aggregate function.

A valid query would be:

```sql
SELECT department, AVG(salary)
FROM employees
GROUP BY department;
```

## Important Rule

When using GROUP BY, selected columns generally need to be either:
1. Included in the GROUP BY, or
2. Wrapped inside an aggregate function.

Example:
```sql
SELECT department, COUNT(*)
FROM employees
GROUP BY department;
```

- `department` → grouped column
- `COUNT(*)` → aggregate

## Interview Questions

**1. What is GROUP BY?**

GROUP BY groups rows with the same values so aggregate calculations can be performed for each group.

**2. Which aggregate functions are commonly used with GROUP BY?**

COUNT(), SUM(), AVG(), MIN(), and MAX().

**3. What is the difference between WHERE and GROUP BY?**

WHERE filters individual rows before grouping. GROUP BY creates groups from the filtered rows.

**4. Can GROUP BY use multiple columns?**

Yes.
```sql
GROUP BY department, job_title;
```

**5. Can GROUP BY be used without aggregate functions?**

Yes, although DISTINCT is often clearer when the goal is simply to return unique combinations.

## Key Takeaways

- GROUP BY creates groups of similar rows.
- It is commonly used with aggregate functions.
- COUNT() counts.
- SUM() totals.
- AVG() calculates averages.
- MIN() finds the minimum.
- MAX() finds the maximum.
- WHERE filters rows before grouping.
- ORDER BY can sort grouped results.
- GROUP BY is one of the most important SQL concepts for Data Science and Analytics.
